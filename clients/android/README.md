# Android-клиент

Black Eagle VPN — отдельный мобильный интерфейс Avalonia UI для Android 11+ (API 30, ARM64 и x86_64). APK 0.5.1 использует общую модель доступа и API, но собственные представления находятся исключительно в `clients/android`; интерфейс Linux не изменяется.

## Экраны и настройки

Версия **0.5.1**: обновлена шестерёнка настроек для светлой и тёмной темы. «Блокировка рекламы» отображается одной строкой с переключателем справа, без дополнительных надписей о DNS и фильтрации. Версия приложения отображается мелким шрифтом по центру под настройками. Порядок применения блокировки не изменился: после переключения нужно переподключить VPN.

Системная кнопка и жест «Назад» возвращают с экранов настроек, серверов и профиля на главную. Из раздельного туннелирования выполняется возврат в настройки. При открытом окне добавления профиля сначала закрывается окно; во время импорта возврат ожидает завершения операции. На главной сохраняется стандартное поведение Android.

Версия **0.5.0**: в настройках появился переключатель «Блокировка рекламы». При следующем подключении клиент отправляет `adblock=true` управляющему API, проверяет подтверждение `adblockEnabled` и использует только выданный API адрес DNS внутри выбранной VPN-ноды. Если сервер не поддерживает фильтрацию или вернул другой DNS, соединение в режиме блокировки не устанавливается; незаметного перехода на обычный DNS нет. В выключенном режиме используется обычный DNS из конфигурации ноды. Переключение при активном VPN применяется после отключения и повторного подключения, поскольку DNS задаётся Android при создании туннеля. Приложение не содержит адресов внешних DNS-провайдеров. Требуется обновлённый backend с [фильтрующим DNS](../../infra/deployment/README.md#12-фильтрующий-dns-для-блокировки-рекламы). Настройка upstream на VPN-ноде остаётся серверной и не управляется приложением.

Если включено раздельное туннелирование, фильтрация распространяется только на приложения, идущие через VPN. Приложения с собственным защищённым DNS и реклама с доменов самого сервиса могут обходить DNS-фильтр.

Проверка 0.5.0 на Samsung SM-S911B: переключатель сохраняется, после переподключения Android показывает DNS туннеля `10.66.0.1`, а Chrome, включённый в VPN, получает `DNS_PROBE_FINISHED_NXDOMAIN` для `doubleclick.net`. Обычный DNS вне VPN разрешает этот домен. Это подтверждает фильтрацию отдельного рекламного домена, но не блокировку всей рекламы в YouTube и других приложениях. Автоматические тесты: 32 из 32; APK проверен `zipalign -P 16`.

Клиент поддерживает автоматическое продление сессии при запуске, перед подключением и по таймеру открытого интерфейса. Неоднозначный `404` и временные ошибки API больше не удаляют профиль. Нужен обновленный API с миграцией `009_session_refresh.sql`: [инструкция](../../infra/deployment/README.md#автоматическое-продление-клиентских-сессий). Уже удаленный профиль или истекшая старая сессия требуют новой ссылки из бота. Обновление токена не продлевает подписку.

Версия **0.4.0**: фоновое подключение из плитки и раздельное туннелирование. Android 11+; данные профиля при обновлении APK сохраняются.

Проверка 0.4.0: 28 автоматических тестов, сборка без предупреждений, проверены подпись APK и ZIP-выравнивание 16 КБ. На Samsung SM-S911B подтверждены подключение из шторки без открытия Activity, handshake, отключение и применение обоих режимов к UID Chrome через `dumpsys vpn_management`. Матрица устройств Android 11–16 и сравнение внешних IP отдельных приложений пока не проверены.

В настройках нажмите «Раздельное туннелирование»: откроется отдельный экран с переключателем, выбором режима, поиском и списком приложений. Кнопка «Назад» возвращает в настройки. Включите опцию и выберите режим:

- «Выбранные приложения без VPN»: отмеченные приложения используют обычную сеть, остальные — VPN.
- «Только выбранные через VPN»: VPN используется только отмеченными приложениями, остальные работают напрямую.

Доступны поиск и выбор приложений с иконкой запуска в текущем профиле Android. Выбор сохраняется между запусками и применяется при **следующем подключении**. Пустой разрешающий список блокирует подключение, в том числе если все выбранные приложения удалены. Пустой список исключений означает VPN для всех. Системный режим Android «Блокировать соединения без VPN» может блокировать доступ исключенных приложений к сети. Правила реализованы через [VpnService.Builder](https://developer.android.com/reference/android/net/VpnService.Builder), без изменения AWG.

Версия 0.3.4 для Android: профиль можно заменить через `+`, даже если после отзыва подписки старый туннель остался активным или восстанавливается. При нажатии «Добавить» старый VPN сначала отключается, затем новая ссылка обменивается через API. Старый токен не требуется для обмена; сессия и ключи не очищаются заранее. При отказе отключения обмен не выполняется и показывается сообщение. Регрессионные тесты проверяют отзыв доступа, зависшее восстановление, успешную замену и сохранение старой сессии при недействительной новой ссылке.

Версия 0.3.3: после измерения пинга остаются только значения задержки у серверов, без постоянного информационного сообщения. Значок профиля рисуется с отступами для обводки.

### Плитка в шторке Android

После установки обновления дважды раскройте шторку, откройте редактирование быстрых настроек и перенесите плитку **Black Eagle VPN** с орлом в активную область. Названия пунктов зависят от прошивки. Плитка защищена системным разрешением `BIND_QUICK_SETTINGS_TILE` и требует разблокировки телефона.

- При активном VPN нажатие отключает собственный туннель без открытия приложения.
- При отключенном VPN foreground-служба загружает сессию, проверяет актуальные права и получает новую конфигурацию, не открывая клиент. Используется сохраненный выбор сервера, затем последний сервер подключения или первый доступный. Без профиля/подписки либо при сетевой ошибке показывается уведомление Toast; приложение автоматически не открывается.
- Если разрешение VPN ещё не выдано или отозвано Android, открывается клиент для системного подтверждения. Это единственное исключение из фонового запуска.
- Плитка активна при подключении, установленном или восстанавливаемом туннеле; повторное нажатие отменяет фоновое подключение. Состояние обновляется при открытии шторки и изменениях VPN. Она не включает произвольный сторонний VPN.

Используется Android TileService; запуск Activity учитывает отдельный PendingIntent API для Android 14+. Системные правила: [Quick Settings tiles](https://developer.android.com/develop/ui/views/quicksettings-tiles). Нельзя считать проверку сборки заменой аппаратного тестирования плитки.

В версии 0.3.2 пинг измеряет отдельный Android-адаптер через `/system/bin/ping`: три ICMP-пробы к IPv4 VPN-ноды, среднее только по полученным ответам. Утилита запускается без shell и root, с ограничением времени и остановкой при отмене. Это устраняет зависимость от пользовательского payload в `System.Net.NetworkInformation.Ping`, который может требовать привилегий. TCP-соединение или время HTTP-запроса не выдаются за ICMP-пинг.

«Нет адреса» означает отсутствие `endpointHost` в каталоге API. «Нет ICMP» означает отсутствие измерения: сервер или сеть могут блокировать ICMP, DNS может быть недоступен, либо системная утилита не разрешена на конкретной прошивке. Доступность AWG по UDP проверяется отдельно подключением. Обновление backend само по себе не меняет способ измерения в уже установленном APK.

В версии 0.3.1 главный экран использует пользовательское изображение `Assets/home-eagle.png` без перекрашивания и кадрирования. Значок приложения не меняется. Пиктограмма включения рисуется в фиксированной области 24×24 с отступом для обводки, чтобы края штриха не обрезались при масштабировании.

После успешного подключения ошибка предыдущей попытки больше не отображается на экранах Android. При новой неудачной попытке ошибка снова видима; независимые сообщения API и подписки не скрываются. Регрессия «ошибка → успех → ошибка» включена в Android-тесты (всего 12).

- **Главная:** эмблема орла, добавление профиля кнопкой `+` слева, настройки справа, круглая кнопка VPN и карточка выбранного сервера. После handshake кнопка загорается зеленым, появляется таймер длительности. Таймер основан на монотонных часах Android, не сбрасывается при смене страницы или сворачивании приложения.
- **Серверы:** реальные локации API, флаги по коду страны, измерение ICMP-пинга, вкладки «Все» и «Избранные». Звезда сохраняет избранное между запусками. Выбор другой локации доступен после отключения VPN. Неизвестный код страны не подменяется вымышленной географией.
- **Профиль:** Telegram ID, статус и срок подписки, обновление данных, переход к боту. `+` принимает новую одноразовую ссылку и заменяет текущий профиль; это не менеджер нескольких одновременных аккаунтов.
- **Настройки:** системная/темная/светлая тема, русский/английский язык и версия APK. Изменения применяются сразу и сохраняются отдельно от зашифрованной сессии.
- Нижняя навигация: Главная, Серверы, Профиль и Telegram. Telegram открывает только `https://t.me/BlackEagleVPNbot` и не отправляет сообщения автоматически.

В макете показаны демонстрационные страны и скорости: приложение не создает таких данных. При отсутствии ICMP показывается «Нет ICMP», а не вымышленная задержка. Профиль и избранное сохраняются при обновлении APK с прежней подписью.

Подключение использует Android `VpnService` и нативную обертку неизмененного `amneziawg-go`. При первом подключении Android запрашивает разрешение на VPN. Статус «Подключено» появляется только после handshake; при его отсутствии запуск отменяется через 35 секунд. UDP-сокеты движка исключаются из собственного туннеля через `VpnService.Protect`. IPv4 и DNS направляются в VPN, IPv6 блокируется Android. Linux helper и root не нужны.

Ключ устройства и последняя конфигурация хранятся зашифрованными с помощью Android Keystore. Перед подключением клиент получает свежую конфигурацию API: сохраненный профиль не обходит проверку подписки. После перезапуска приложения подключение запускается вручную.

## Сборка

Команды выполняются из `clients/android`. Требуются .NET SDK 10, workload `android`, Android SDK, JDK 17, Go 1.25 или новее и Android NDK r28c. Проверенная среда: JDK 17, Go 1.27.1, NDK 28.2.13676358. Укажите собственные пути SDK/JDK:

```bash
dotnet workload install android
export ANDROID_SDK_ROOT="$HOME/Android/Sdk"
export ANDROID_NDK_HOME="$ANDROID_SDK_ROOT/ndk/28.2.13676358"
"$ANDROID_SDK_ROOT/cmdline-tools/latest/bin/sdkmanager" 'ndk;28.2.13676358'
bash deploy/build-native.sh
dotnet build src/BlackEagle.Android/BlackEagle.Android.csproj \
  -t:InstallAndroidDependencies \
  -p:AndroidSdkDirectory="$HOME/Android/Sdk" \
  -p:JavaSdkDirectory=/usr/lib/jvm/java-17-openjdk-amd64 \
  -p:AcceptAndroidSDKLicenses=true
dotnet build src/BlackEagle.Android/BlackEagle.Android.csproj -c Debug \
  -p:AndroidSdkDirectory="$HOME/Android/Sdk" \
  -p:JavaSdkDirectory=/usr/lib/jvm/java-17-openjdk-amd64
```

## Установка через ADB

После включения отладки по USB и подтверждения ключа компьютера на смартфоне:

```bash
adb devices -l
adb install --no-incremental -r src/BlackEagle.Android/bin/Debug/net10.0-android/com.blackeaglevpn.client-Signed.apk
```

`-r` обновляет приложение с сохранением данных при той же подписи APK. Не удаляйте приложение перед обновлением: удаление уничтожает сохраненную сессию и ключи. Для самостоятельной установки .NET APK в проекте включено `EmbedAssembliesIntoApk=true` — приложение не зависит от Fast Deployment из IDE. Debug APK предназначен для проверки; для распространения необходима постоянная release-подпись.

## Совместимость с размером страницы 16 КБ

Android-проект использует SkiaSharp 3.119.4, а AWG собирается с `-z max-page-size=16384`. Проверять нужно и ELF-сегменты всех `.so` внутри APK (выравнивание LOAD не меньше `0x4000`), и упаковку APK:

```bash
"$ANDROID_SDK_ROOT/build-tools/36.0.0/zipalign" -c -P 16 -v 4 \
  src/BlackEagle.Android/bin/Debug/net10.0-android/com.blackeaglevpn.client-Signed.apk
```

Успешная статическая проверка не заменяет запуск на устройстве или эмуляторе с размером страницы 16 КБ. Размер страницы подключенного устройства: `adb shell getconf PAGE_SIZE`.

Тесты Android-локализации, не требующие устройства: `dotnet test tests/BlackEagle.Android.Tests/BlackEagle.Android.Tests.csproj`. Минимальная версия проверяется в итоговом APK через `aapt dump badging`: `sdkVersion:'30'`. Сборка для API 30 не заменяет отдельный прогон на Android 11; аппаратная проверка выполнялась на Android 16.

Проверка интерфейса 0.3.0 на Samsung SM-S911B: главная и нижняя навигация, окно импорта (без замены действующей сессии), избранное, английская локализация профиля, переключение светлой темы. Подключение к Frankfurt подтверждено handshake, зеленой индикацией и таймером; после сворачивания и возвращения таймер продолжает отсчет. Тема, язык и избранное сохраняются при обновлении APK. 10 тестов локализации проходят; подпись APK и `zipalign -P 16` проверены. Для новых стран флаг зависит от корректного ISO-кода в API.

Проверено 14.09.2026: сборка 0.2.0 устанавливается поверх предыдущей с сохранением сессии на Samsung SM-S911B / Android 16 (страницы 4 КБ). Получен handshake на Frankfurt 1 и Helsinki-1, проверено отключение. При подключении к Helsinki-1 DNS и ICMP до `blackeagle-vpn.com` от UID приложения работают. Все 636 ELF-библиотек проверенного Debug APK имеют LOAD alignment не меньше 16 КБ; `zipalign` и проверка подписи проходят. Клиентские тесты: 17 из 17. Запуск на системе с реальными страницами 16 КБ пока не проверен.
