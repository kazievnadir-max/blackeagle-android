# Black Eagle VPN для Android 0.5.4

Android 11 и новее, ARM64 (`arm64-v8a`), versionCode 14.

- Убрана надпись «Проверка обновлений…» из настроек.
- После ручной проверки без обновлений показывается краткое системное уведомление «Установлена актуальная версия программы» (около 4 секунд).
- Автоматическая проверка без обновлений не показывает уведомлений.
- Отсутствующий канал обновлений теперь отображается как ошибка проверки.

APK подписан постоянным ключом Black Eagle VPN. Устанавливается поверх версии с тем же сертификатом. Версии 0.5.2 и ниже требуют ручной загрузки: встроенная проверка обновлений появилась в 0.5.3.

Сборка Release: 0 ошибок и предупреждений. 48 тестов пройдены. Подпись APK, SHA-256, выравнивание 16 КБ и подписанный манифест проверены. Установка и уведомление на физическом Android-устройстве в этой проверке не выполнялись.
