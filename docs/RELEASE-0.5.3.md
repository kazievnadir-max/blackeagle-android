# Black Eagle VPN 0.5.3

Android 11+, ARM64; `versionCode=13`.

Добавлены обновления из `kazievnadir-max/blackeagle-release`: автоматическая и
ручная проверка, уведомление о новой версии, описание и размер загрузки,
процент выполнения, отмена и повтор. Перед установкой проверяются подписанный
манифест, SHA-256, размер, идентификатор пакета, версии и сертификат подписи APK.
Установку подтверждает пользователь в системном установщике Android.

## Проверка и статус

- Release ARM64: 0 предупреждений, 0 ошибок.
- 48 автоматических тестов пройдены.
- Подпись APK и выравнивание 16 КБ проверены.
- Реальный манифест, подписанный OpenSSL, и APK проверены кодом UpdateClient
  с отключенной reflection-сериализацией JSON (как требуется при trimming).
- Файлы подготовлены локально; выпуск и канал в GitHub пока не опубликованы.
- Подключенного Android-устройства нет. Интерфейс на устройстве и полный путь
  установки поверх существующей версии еще не проверены.

Первый APK с обновлением необходимо установить вручную. Для полного сквозного
теста потребуется более новая тестовая версия с тем же ключом. Не следует
подменять метаданные или APK действующего стабильного выпуска ради проверки.

Порядок публикации и хранения ключей: [ANDROID-UPDATES.md](ANDROID-UPDATES.md).
