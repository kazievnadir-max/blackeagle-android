# Black Eagle VPN для Android 0.5.6

Android 11 и новее, ARM64 (`arm64-v8a`), versionCode 16.

- Движок AmneziaWG обновлен до v3.1.20261116, включая исправление гонки таймеров, влияющей на handshake и keepalive.
- Обновлены Go-зависимости: x/crypto v0.59.0, x/sys v0.50.0, x/net v0.63.0.
- Сохранено исправление полного отключения VPN через плитку в шторке.

Сборка использует Go 1.27.1. APK подписан постоянным ключом Black Eagle VPN;
обновление поверх версии с тем же сертификатом сохраняет профиль и настройки.

SHA-256 сертификата: `990b9d5a3fafd367facde05cceada668ba2f6210da84d2d07e5a2cfa820ce383`.
Контрольная сумма APK находится в приложенном `SHA256SUMS.txt`.

Выпуск: https://github.com/kazievnadir-max/blackeagle-release/releases/tag/android-v0.5.6.

Проверки: Release собран без ошибок и предупреждений, 48 тестов клиента пройдены.
Тесты AWG `device` и `conn` прошли с `-race` на Linux с обновленными зависимостями.
Проверены подпись APK, подписанный канал, ZIP-выравнивание и ELF-выравнивание
всех 98 нативных библиотек для страниц 16 КБ.
Телефон при подготовке выпуска не подключен: проверка на Android-устройстве
и длительного соединения для этой версии не выполнялась.
