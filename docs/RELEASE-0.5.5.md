# Black Eagle VPN для Android 0.5.5

Android 11 и новее, ARM64 (`arm64-v8a`), versionCode 15.

- Исправлено отключение VPN через плитку в шторке: системный TUN-дескриптор
  закрывается явно, поэтому VPN-интерфейс и маршруты освобождаются сразу.
- Исправлена очистка дескриптора при ошибке запуска AWG.
- Для полного отключения больше не требуется открывать приложение.

APK подписан постоянным ключом Black Eagle VPN. Обновление сохраняет профиль
и настройки при установке поверх сборки с тем же сертификатом.

SHA-256 сертификата APK: `990b9d5a3fafd367facde05cceada668ba2f6210da84d2d07e5a2cfa820ce383`.

Выпуск: https://github.com/kazievnadir-max/blackeagle-release/releases/tag/android-v0.5.5.
Контрольная сумма APK публикуется в `SHA256SUMS.txt` вместе с выпуском.

Проверки: Release собран без ошибок и предупреждений; 48 тестов пройдены.
Подпись APK, выравнивание 16 КБ и подпись канала обновлений проверены.
Версия 0.5.5 установлена поверх 0.5.4 на Samsung SM-S911B с сохранением профиля.
Включение через плитку, трафик внутри туннеля, отключение без открытия приложения,
исчезновение TUN и VPN-службы и обычный интернет после отключения проверены.
